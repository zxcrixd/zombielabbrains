🧪 Об игре

В Зомби-лаборатории 3D вы управляете безумным учёным, который создаёт армию зомби для захвата окрестных деревень. Издание Basic Edition включает упрощённый геймплей:

🫧 Пузырьки

Лопайте пузырьки, нажимая соответствующие клавиши, чтобы получать мозги. Улучшайте силу лопания за мозги.

⚔️ Стратегия

Атакуйте ближайшие поселения, захватывайте их и получайте мозги.

📜 Миссии

Две обучающие миссии: первый зомби и первая атака. Награда — мозги.

🧩 Моды

Поддержка пользовательских модов через папку mods.

⚙️ Установка и запуск

Требования

  • ✅ Python 3.7 или выше
  • ✅ Библиотека Pygame

Шаги

  1. Установите зависимости: pip install pygame
  2. Сохраните файл main.py в отдельную папку.
  3. Запустите игру: python main.py

Быстрый старт

# 1. Создайте папку проекта
mkdir zombie_basic
cd zombie_basic

# 2. Установите Pygame
pip install pygame

# 3. Сохраните main.py (см. документацию)

# 4. Запуск
python main.py

🧠 Игровые механики

🏭 Производство зомби

  • Подойдите к столу (коричневый квадрат на карте) и нажмите E.
  • Лопайте пузырьки, нажимая указанные на них клавиши, чтобы получать мозги.
  • При накоплении 1000 мозгов автоматически создаётся 1 зомби.
  • Силу лопания можно улучшить за мозги (кнопка «Улучшить лопание»).

⚔️ Атака деревень

  • Подойдите к компьютеру (бирюзовый квадрат) и нажмите E.
  • Выберите пункт «Атака деревень».
  • Стрелками ↑ / ↓ выберите цель.
  • Нажмите «Атаковать».
  • Победа приносит мозги и захватывает деревню. Поражение уменьшает армию наполовину.

📋 Миссии

Первый зомби — создайте хотя бы одного зомби.
Атака деревни — захватите первую деревню.

За выполнение миссий начисляются мозги — внутриигровая валюта.

🔧 Поддержка модов

Игра автоматически загружает пользовательские моды из папки mods, расположенной рядом с main.py.

Как создать мод

  1. Создайте в папке mods файл с расширением .py (например, cheap_zombies.py).
  2. Внутри определите функцию apply_mod(game), которая изменяет параметры игры.
Пример мода (mods/cheap_zombies.py): 
def apply_mod(game):
    game.zombie_cost = 50      # снижаем стоимость зомби
    game.click_power = 2       # увеличиваем силу лопания пузырьков

После запуска игры мод будет автоматически применён.

Настройки

В главном меню доступны:

  • Полноэкранный режим (переключение).
  • Выход из игры.
