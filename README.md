# Зомби-лаборатория 3D — Basic Edition (BAS)

**Зомби-лаборатория 3D** — это псевдо-трёхмерная игра с элементами кликера и стратегии. Игрок управляет безумным учёным, который создаёт армию зомби и захватывает деревни. Издание **Basic Edition** включает упрощённый геймплей: производство зомби через кликер, улучшение клика, две обучающие миссии и атаки на ближайшие поселения.

---

## Требования

- Python 3.7 или выше
- Библиотека Pygame

## Установка и запуск

1. Установите зависимости:
   pip install pygame
2. Сохраните файл `main.py` в отдельную папку.
   
3. Запустите игру.
   python main.py

## Игровые механики

### Производство зомби
- Подойдите к **столу** (коричневый квадрат на карте) и нажмите `E`.
- Нажимайте кнопку **«Кликнуть»**, чтобы набирать очки кликов.
- При накоплении 100 очков автоматически создаётся 1 зомби.
- Очки кликов можно улучшить за мозги (кнопка **«Улучшить клик»**).

### Атака деревень
- Подойдите к **компьютеру** (бирюзовый квадрат) и нажмите `E`.
- Выберите пункт **«Атака деревень»**.
- Стрелками `↑` / `↓` выберите цель.
- Нажмите **«Атаковать»**.
- Победа приносит мозги и захватывает деревню. Поражение уменьшает армию наполовину.

### Миссии
1. **Первый зомби** — создайте хотя бы одного зомби.
2. **Атака деревни** — захватите первую деревню.

За выполнение миссий начисляются мозги — внутриигровая валюта.

## Поддержка модов

Игра автоматически загружает пользовательские моды из папки `mods`, расположенной рядом с `main.py`.

### Как создать мод
1. Создайте в папке `mods` файл с расширением `.py` (например, `cheap_zombies.py`).
2. Внутри определите функцию `apply_mod(game)`, которая изменяет параметры игры.

**Пример мода** (`mods/cheap_zombies.py`):
```python
def apply_mod(game):
    game.zombie_cost = 50      # снижаем стоимость зомби
    game.click_power = 2       # увеличиваем силу клика
```

После запуска игры мод будет автоматически применён.
